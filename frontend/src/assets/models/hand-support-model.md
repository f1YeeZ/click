# 手掌支撑模型

`hand-support.glb` 是用于支撑位置涂抹和热力图呈现的写实成年人右手模型。

## 项目资源

- 格式：glTF 2.0 Binary（GLB）
- 网格：38,252 个上传顶点，58,204 个三角面
- 大小：约 1.17 MB
- 贴图：1024 × 1024 WebP，包括基础色、法线和金属度/粗糙度
- UV：保留源模型 UV 供写实材质使用；支撑热力数据按掌面 XY 投影映射，继续兼容现有 24 × 32 标准网格
- 压缩：`KHR_mesh_quantization` 和 `EXT_texture_webp`
- 朝向：模型高度沿 Y 轴，掌心正面朝 +X；在 Three.js 中设置 `rotation.y = -Math.PI / 2` 可使掌心朝 +Z
- 切线：源 UV 存在少量退化点，未写入切线；由 WebGL 材质在运行时计算切线空间
